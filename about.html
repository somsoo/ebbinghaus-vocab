🧠 망각곡선 보카 부스터 소개

망각곡선 보카 부스터는 단어를 단순히 깜지 쓰듯 맹목적으로 외우다 쉽게 포기하는 수험생과 학습자들을 위해, 뇌과학자 헤르만 에빙하우스의 망각곡선(Forgetting Curve)과 최신 간격 반복(Spaced Repetition) 알고리즘을 직관적으로 결합한 지능형 보카 플래시카드 도구입니다.

💡 기획 취지: "뇌는 잊어버리기 직전, 스스로 힘겹게 회상하려 할 때 가장 강력하게 시냅스를 연결한다." — 최적의 골든 타임 복습 시점을 실시간 시각화하여 단어의 장기기억 고착화를 지원합니다.

1. 학술적 근거 및 알고리즘 기준

  • 에빙하우스 망각곡선 모델: 기억 잔존율 $R = e^{-t/S}$ (t는 경과 시간, S는 기억 안정도). 복습을 거듭할 때마다 감쇠 기울기 S가 지수적으로 완만해지는 과정을 SVG 차트로 실시간 시각화합니다.
  • FSRS (Free Spaced Repetition Scheduler) 4단계 평가: 다시(Again, 1분), 어려움(Hard, 1일), 보통(Good, 3일), 쉬움(Easy, 7일)의 점진적 복습 주기 계산.
  • 능동적 인출(Active Recall): 앞면에서는 예문의 핵심 단어를 빈칸 처리하여 수동적 읽기가 아닌 적극적인 뇌 자극 유도.
  • 다감각 통합 학습: Web Speech API를 활용한 원어민 음성 낭독 및 Web Audio API 차임벨 피드백.

2. 100% 브라우저 클라이언트 연산 보증

망각곡선 보카 부스터의 모든 단어 데이터, 개인별 복습 주기 계산, 학습 이력 및 커스텀 단어장은 외부 서버로 전송되지 않고 사용자의 기기 브라우저(LocalStorage) 내에서만 100% 안전하게 보관됩니다.
